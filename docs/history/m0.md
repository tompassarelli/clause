# Clause M0 evidence checkpoint

> **Status:** Historical; superseded.
>
> **Authority:** This page records a completed design checkpoint. It is not
> authoritative for current Clause syntax, semantics, or implementation order.
>
> **Relationship:** Superseded by the current
> [semantic foundation](../foundation.md), [target surface](../surface.md), and
> [roadmap](../roadmap.md), together with the implemented semantic-v8 referent
> kernel and Revision-v5 wire.

## What M0 established

M0 was the point at which Clause stopped treating the proposed surface as
informal prose and required explicit contrast evidence. It made several
lasting requirements reviewable:

- source layout must lower to explicit role-labelled structure;
- terms and spellings must remain distinct from semantic identity;
- relation content, assertion occurrence, and judgment must not collapse;
- named holes correlate while anonymous holes remain fresh;
- open-world absence must remain distinct from denial;
- laws, derivation rules, invariants, goals, transitions, and effects require
  distinct modal behavior;
- a focused block must elaborate without inventing objects or fields;
- exact Revisions and Deltas must preserve lineage and provenance;
- current executable behavior must remain a migration oracle while the surface
  changes.

M0 also established two-space, spaces-only target layout and required clear
diagnostics for tabs and structurally ambiguous forms.

## What M0 no longer governs

The checkpoint's punctuation ruling was later replaced. Current authoring uses:

```clause
gravity: 9.81
Chess ∈ Game
x = y
input -> result
```

`:` now means binding only. `∈` is canonical membership. A human-facing
editor may transform typed `::` into `∈`; raw `::` is not Clause grammar.
`=` remains equality, `->` remains production/result orientation, and canonical
target layout remains two spaces with no tabs.

The old M0 fixture tree was not consumed by the Rust build, parser, or tests
and is not retained in the live repository. Current executable evidence lives
in `tests/`, `src/**/tests.rs`, and the programs under `examples/`.

## Implementation outcome

The successor kernel replaced the legacy semantic foundation with:

- one stable `ReferentId` domain;
- n-ary `RelationalContent` with named roles;
- separate `AssertionOccurrence` and `Judgment` structures;
- relational admissibility rather than a primitive Type universe;
- explicit definitions, derivation rules, universal laws, invariants, goals,
  and transitions;
- an open-world operative judgment model;
- canonical `clause-semantic-v8` / `clause-revision-v5` persistence;
- strict successor reload against one exact predecessor and complete Delta.

The native parser still accepts the ceremonial four-space declaration profile
as executable migration evidence. The [target surface](../surface.md) governs
its replacement.

## Historical value

M0 remains useful for understanding the transition from a typed, declaration-
heavy prototype to a distinction-first relational system. It is deliberately
kept as history rather than a parallel specification: current work must follow
the current documents linked above.
